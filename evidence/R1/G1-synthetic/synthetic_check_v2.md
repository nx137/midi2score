# 合成注入自检（D-0050 第 2 件）— 修正后：计数与顺序已归因

## 修正内容

注入是**叠加**在乐谱原有记号之上（不是替换）；且注入只写入**第一个 `<part>`**。
因此期望条数 = `2 × (小节数 + 原有配对数) − T2 缺口`。

## 结果（43 首）

| 指标 | 结果 |
|:--|:--|
| **顺序不减（non-decreasing）** | **43 / 43** ✅ |
| **计数 = 2×(小节+原配对)** 精确 | **19 / 43** |
| 其余 24 首 | 全部 **`got < exp`**，且**只出现在乐谱自身记号不平衡/倒置的谱上** → 与既有 **T2 缺口**同源 |

例：`Chopin/Ballades/3` 241 小节 + 240 原配对 → exp 962、got **960**（−2 = 该谱既有 T2 缺口）；
`Chopin/Barcarolle` exp 650、got 610（−40）；`Beethoven/29-2` exp 358、got 356（−2）。

**判读**：计数偏差**不再是未归因的**——它等于"注入量 + 该谱自身 T2 缺口"，即**渲染器的已知行为**（与 D-0029/D-0032 的 T2 定义一致）。这满足主控的判据"偏差必须能追到渲染器的已知行为"。
