- 本层是**正确性问题**，不是性能问题：`inversion_baselines.py` 的 bootstrap **按 score 重采样**且只对逐 run 计数求和（不 pool、不重调 `f1_of`）；我写的 pooled 版本会让点估计（逐 run 计数）与 CI（pooled 匹配）成为两个不同估计量。
