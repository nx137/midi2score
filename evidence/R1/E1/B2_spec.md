# B2 规格（冻结原文，2026-10-08）

## 定义

- **阈值** = CC64 二值化（D-0030），**不是** d_min（裁决：B2 = CC64 + 和声，增量相对 B1 才可归因）。
- **d_min 固定 = 0**（依 B1 的 CV 结论：去抖无增益）。**唯一自由超参 = K。**

## 规则

- 锚点域、音符集合、`bass_pc`、`pcs` **一律沿用** `score_features.anchor_features`（不重写）。
- **空锚点**（`n_notes == 0`）：继承前一个非空锚点的 `bass_pc` 与 `pcs`（zero-order hold）；
  首锚点为空则继承其后第一个非空锚点。
- **Step 1 边界锚点** t 满足任一：
  (a) `bass_pc(t) != bass_pc(t-1)`（低音变化）
  (b) `|pcs(t) Δ pcs(t-1)| >= K`（音级集合变化量）
  (c) t 是小节首锚点（beat）
  序列首锚点恒为边界。
- **Step 2 段** = 相邻两边界锚点之间的区间 `[ta, tb)`；段内**任一锚点 CC64 二值状态为 ON** → 该段**激活**。
- **Step 3** 激活段 → pred 加入 `(ta, DOWN)` 与 `(tb, UP)`。未激活段不输出。
- **K 网格 = {1, 2, 3}**；train 折内 5 折 CV，准则同 B1（各折 F1@±1 算术平均最大，平局取更小 K）；
  val 一次（健全性）、test 一次。

## 设计性质

**位置由和声/拍点决定，存在性由 CC64 决定** —— 即「在不降 DOWN recall 的前提下提高 DOWN precision」；
和声段数应远少于反演的 132,116，而每段恰给一对 DOWN/UP。

## 报数

主口径 **±1 拍 / test 折 / 同域**；对照**必须含 bp2 与 bp4**；必须报 **DOWN/UP 分标签 P/R/F1**（§15 强制披露）
+ micro/macro + 绝对计数（漏检/虚报/错向）+ 逐曲配对 bootstrap 10,000。
产物：`results/E1/B2_perf.csv` + `B2_summary.md/json`，两张表分开，CV 五折数字与选中 K 入 evidence，
完整命令行原样入 evidence。

## 停机条件（仅三类）

① 规格未写的取值要发明；② 规格自相矛盾；③ K 各折最优跨越全部 3 档。
**禁止**因分数低/不如预期停机。**不得修改** B1、`score_features`、匹配器或任何既有文件——只能新增。

## 预先声明的判读

| 现象 | 含义 |
|:--|:--|
| DOWN F1 > 0.4457 | 和声信息有效，目标 1 达成 |
| DOWN F1 ≈ 0.4457 | 和声不比"机械每小节踩一下"提供更多信息——本身是可报的对照结论 |
| DOWN F1 < 0.4457 | 优先查段划分粒度（K 是否过大/过小），再报 |
| UP F1 大幅低于 0.3379 | 段的 UP 位置系统性偏移，查段边界定义 |

> B2 无论结果如何**都不阻塞 B3**——§5.2 给它的角色就是「必做对照，证明非平凡」。真正的目标在 B3。
